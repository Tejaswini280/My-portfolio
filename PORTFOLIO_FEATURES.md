## 🎭 Animations & Effects

### On Page Load
1. Fade-in effect for entire page
2. Typing animation for hero subtitle
3. Floating animation starts for profile picture

### On Scroll
1. **Parallax effect** - Hero section moves slower than scroll
2. **Fade-in animations** - Sections appear as you scroll down
3. **Active navigation** - Current section highlighted in navbar
4. **Progress bar** - Thin colored bar at top shows scroll progress
5. **Counter animation** - Statistics count up when visible

### On Hover
1. **Buttons** - Lift up with shadow, ripple effect on click
2. **Project cards** - 3D tilt effect following mouse movement
3. **Skill tags** - Random color change, lift up
4. **Social icons** - Pulse animation, color change
5. **Navigation links** - Color change, underline appears
6. **Certification cards** - Slide right slightly

### Continuous Animations
1. **Profile picture** - Gentle floating (up and down)
2. **Timeline dots** - Subtle pulse effect
3. **Gradient text** - Color shift animation
4. **Scroll indicator** - Bounce animation (if added)
